# Clinical Follow-up Mobile Application

A cross-platform mobile application designed to support **clinical follow-up studies for post-discharge patients**.  
The system enables continuous health reporting, patient–nurse communication, and questionnaire-based outcome collection in a real hospital research setting.

---

## Overview

This project was developed in collaboration with a medical PhD research team to support a **controlled clinical follow-up experiment**.

Patients discharged from hospital used the application for:

- Daily health status reporting  
- Medication, diet, and exercise guidance  
- Questionnaire submission  
- Direct messaging with nurses  

Clinical staff used a separate interface to:

- Manage patient accounts  
- Distribute questionnaires and materials  
- Monitor submitted health data  
- Export results for research analysis  

The system was **used in a real experimental setting** for evaluating the impact of digital follow-up on patient outcomes.
